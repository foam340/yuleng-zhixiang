# 工程结构与维护约定

微信开发者工具始终打开 `coldchain-platform/`。根目录保留package.json、项目配置、README和Agent约定，其他内容按职责分目录。

| 目录 | 职责 | 修改场景 |
|---|---|---|
| `miniprogram/pages/` | 工作台、资源池、预约、订单、账户、详情页面 | 调整界面、入口及页面事件 |
| `miniprogram/core/` | 可复用的评分、分配、库容和履约业务规则 | 改算法、状态流转和规则 |
| `miniprogram/services/` | 页面调用的数据访问层，可切换本地与远程模式 | 改持久化、接口连接和错误处理 |
| `miniprogram/styles/` | 集中的颜色/字体令牌、控件与页面样式 | 调整视觉系统 |
| `miniprogram/utils/` | 订单显示状态、阶段和资源余量等展示计算 | 调整界面表达，不改业务规则 |
| `miniprogram/assets/` | 小程序实际使用的品牌图片与细线图标 | 更新发布包中的视觉素材 |
| `server/` | 独立演示API、访问码、会话工作区和文件持久化 | 部署后端、改接口或存储 |
| `tests/` | 业务、接口与页面流程测试 | 验证业务改动与修复回归 |
| `scripts/` | 工程检查、微信编译、布局预览工具 | 改开发工具与验证流程 |
| `docs/` | 已实现规则、演示脚本、上线准备与工程说明 | 改文档、排练与交接 |
| `artifacts/` | 生成文件及本机检查缓存 | 查看验证结果，不在这里写业务代码 |
| `data/` | 可选后端运行时生成的演示工作区 | 服务按需创建，按部署策略备份 |
| `.git/` | 代码工程的Git元数据 | 使用Git命令管理，不手动整理其内部文件 |

## 小程序内的文件

`app.js`、`app.json`、`app.wxss` 分别是程序入口、页面/导航配置和公共样式。`config.js` 决定本地或远程演示模式，不能放入AppSecret或旧项目凭据。`sitemap.json` 是小程序搜索索引配置。

每个pages子目录对应一个页面。`index.js` 是页面事件与数据，`index.wxml` 是布局。共享业务规则仍位于小程序包内，以便本地模式运行；服务端直接复用该模块，不复制另一套算法。

## 生成物与开发脚本

| 位置 | 内容 | 如何产生 |
|---|---|---|
| `artifacts/build/` | 编译后的WXML、WXSS脚本 | `npm run compile:wechat` |
| `artifacts/previews/` | 375/390宽度的HTML布局预览及index.html | `npm run preview:layout`，自动先编译 |
| `artifacts/screenshots/` | 当前及历史界面检查截图 | 浏览器或人工检查时保存 |
| `artifacts/cache/` | 隔离的Edge用户配置和检查缓存 | 后续无头浏览器检查将用户目录设在这里 |
| `artifacts/archive/` | 本次大改前的前端备份 | 重做前保留，不上传小程序包 |

布局预览不是可操作的小程序，也不代表真机测试通过。首版截图中部分文件名带有v2或affordance，按原名保留历史证据，本次未删除。

`npm run capture:layout` 对预览执行隔离Edge截图和布局检查，当前截图及report.json保存在 `artifacts/screenshots/redesign/`。`scripts/build-icons.ps1` 为本地PNG图标生成源代码；`DESIGN.md` 记录前端设计约定及实际验证范围。

Windows本机已安装微信开发者工具时，编译脚本会查找其wcc-exec目录。安装路径不同时，可通过环境变量 `WECHAT_COMPILER_DIR` 指向含wcc.exe、wcsc.exe的目录，不把本机安装路径写死在每条临时命令中。

## 版本控制与配置边界

提交源代码、测试、脚本、公开文档、package.json、project.config.example.json、忽略规则和.env.example。执行 `npm run setup:wechat` 生成本机 `project.config.json`，已有配置不会覆盖；该文件与 `project.private.config.json` 均不提交。

忽略artifacts、data、node_modules、真实.env和密钥文件。原始方案、品牌源文件、本机资源和内部交接记录不属于公开仓库；运行需要的精简品牌图片随源码提供。

当前代码使用本地比赛演示模式。公开源码不包含原账号的发布记录；独立发布参见[上线准备](上线准备.md)。需要接入服务器时使用独立服务、数据、端口和凭据。
