# 渝冷智享小程序使用说明

渝冷智享，让冷库与运力共享更高效。

本说明适用于2026年10月29日整理的版本，供队友、评委及体验者使用。小程序展示冷库共享、需求分配、入库运输、积分结算和溯源处置流程。企业、资源、订单、费用及温控记录均为模拟，不产生实际仓储、运输或支付服务，请使用虚构资料。

## 一、先认识五个入口

通过小程序分享卡片或小程序码进入。底部导航提供以下功能：

| 入口 | 可以做什么 |
|---|---|
| 工作台 | 切换企业、新建预约、查看进行中预约、运行六企业案例 |
| 资源池 | 按温区和日期查看冷库、了解共享车辆、发布闲置冷库 |
| 预约 | 填写冷库需求，提交后查看分配结果 |
| 订单 | 筛选预约、处理应急协作、入库、配车及完成运输 |
| 我的 | 切换企业、查看共享收益、进入积分与共享服务、恢复演示数据 |

“我的预约”指当前所选模拟企业的订单。查看其他企业订单，可以在“订单”中选择“全部企业案例”；执行操作前需切换到相应企业。

## 二、第一次使用：完成一笔预约

推荐先体验一笔小订单，再查看多企业资源竞争案例。

### 1. 选择企业并查看资源

1. 在“工作台”点击企业卡片右侧的“切换”，选择想体验的模拟企业。
2. 进入“资源池”，设置计划入库日期、存储天数和温区。
3. 查看各库区的可用库容、单价和隔离条件，点击“预约冷库”。也可以直接从工作台点击“新建预约”。

从资源池进入预约时，会带入温区和时段。所选库区是参考资源，最终分配以提交后的结果为准。

### 2. 填写并提交预约

可先按以下示例填写：

| 项目 | 示例 |
|---|---|
| 温区 | 冷藏2–8℃ |
| 需求库容 | 10m³ |
| 存储天数 | 3天 |
| 计划入库日期 | 与资源池查询日期一致 |
| 药品类别 | 模拟生物制品 |
| 独立隔离储位 | 首次体验可关闭 |
| 演示季节价格 | 平季：基准价 |
| 紧急程度 | 普通备货 |
| 未及时入库的风险 | 低风险 |

点击“提交并查看分配方案”，查看已获配库容、费用预估及库区。点击评分区域的“查看明细”，可以看到贡献度、紧急度、风险度和等待时长的得分构成。

选择临床急需或急救时，需要同时打开表单中的模拟急需证明开关。

### 3. 确认预约并登记入库

1. 在订单详情点击“确认预约”；若只获配部分库容，按钮显示“确认已获配部分”。
2. 确认后点击“使用模拟入库码”，即可体验入库流程。
3. 如使用“扫码登记入库”，二维码内容须与该订单的完整订单号一致。

仅获配的部分可以入库。未满足部分不会自动入库，也不会自动顺延到其他日期。

### 4. 申请配车并完成运输

1. 入库后点击“申请出库配车”。
2. 填写本批次体积、重量及最晚到达时间，例如10m³、1吨、120分钟。
3. 点击“匹配车辆”，查看车辆及模拟运费。
4. 点击“完成本批模拟运输”。全部已分配货物运完后，订单显示“已完成”。

运量较大时需要分批运输。一辆车执行运输期间不会再次分配给其他订单；没有合适空闲车辆时，可以先完成已有运输，或调整本次运量、时限。

## 三、快速查看六企业竞争案例

1. 在“工作台”下方找到“旺季资源争用案例”，点击“运行六企业案例”。
2. 进入“订单”，选择“全部企业案例”，查看各企业的需求、获配量和状态。
3. 打开订单，查看评分明细及保底分配说明；需要确认或履约时，点击“切换到该企业”。

应急协作推荐查看B12新接入企业的订单：

1. 打开应急待响应的订单，点击“切换供给方并处理”。
2. 在“需要我响应的协作”区域，点击使用相应冷库响应的按钮。
3. 供给方接受后，切回需求企业，确认预约并继续入库运输。

应急资源只有在供给方接受后才算锁定。已有其他预约时，重新演示六企业案例会提示恢复初始数据；确认后会清空当前模拟记录，请先保存需要展示的信息。

## 四、积分、保底与账单

入口：**我的 → 常用服务 → 积分与共享服务 → 权益与账单**。

### 积分与费用

- 可以查看积分月汇总、逐笔来源、已使用数量和到期日。积分自获得之日起12个月有效。
- 发布冷库产生的积分按“库容×投放天数×温区系数”计算；冷藏系数1.0，冷冻系数1.3。
- 完成车辆运输按“台次×里程×温控系数”记分；应急协作全部履约后追加供给方收益5%的积分。
- 订单全部履约后，在对应账单点击“用积分抵扣仓储服务费”。按1积分抵1元，最多抵扣该订单的平台仓储服务费部分，不抵扣供给方收入。

基准仓储价为冷藏3.5元、冷冻5元，每m³每天；可在预约时选择旺季上浮20%或淡季下浮15%。自行发布的库区按其报价计算，最终以订单账单为准。费用及抵扣均为模拟，不涉及充值、提现或真实兑换。

### 保底额度

- 历史企业：填写完整12个月的月使用库容，以逗号分隔，按平均值的80%核定。
- 新企业：历史用量留空，填写生产计划库容，打开“模拟联盟审核已确认计划”，点击“核定模拟保底额度”。

保底用于后续资源分配，不会重新挤占已分配订单的库容。此处为机制体验，不是实际资质审核。

### 模拟退出

在该页下方点击“申请30天后模拟退出”并确认。生效后取消保底且不能继续投放联盟资源，已有订单仍可履约，未过期积分保留，也可继续按需付费预约。

## 五、溯源、告警与七天供需

### 查询订单档案

在订单详情点击“查看模拟溯源档案与告警”，可以直接打开该订单档案。也可从“积分与共享服务”进入“溯源与告警”，输入完整订单号后点击“查询档案”，或扫描内容为订单号的二维码。

档案展示提交、确认、入库及运输等操作记录。当前记录未接联盟链，不提供真实链上核验或监管报送证明。

### 体验告警闭环

查询当前企业处于“存储中”或运输中的订单，点击“演示严重超温告警”。然后在工单中依次点击：

**模拟人员响应 → 模拟完成处置 → 归档并复盘**。

同一订单已有未归档告警时，需先处理该工单。温度样本与告警均为模拟，没有接入真实传感器或发送实际通知。

### 查看七天供需

在共享服务中选择“七天供需”，按日期和温区查看登记需求、可用余量及“建议错峰”提示。结果根据当前已登记订单计算，尚未录入的需求不包含在内。

## 六、发布资源、转发与恢复数据

**发布冷库：** 进入“资源池”，点击“发布我的闲置冷库”，填写起始日、投放天数、名称、温区、库容和单价，按需选择隔离储位或仅用于应急协作，再点击“发布模拟资源”。发布资源仅在投放时段内可分配，预约时段须在其范围内。

**转发小程序：** 点击右上角“…”中的转发入口，发送给好友或群聊。卡片使用冷库与冷藏车封面，标题为“渝冷智享，让冷库与运力共享更高效”；接收者打开后进入工作台。

**重新开始：** 在“我的”底部点击“恢复演示数据”，阅读提示并确认。此操作会清空当前模拟预约、发布资源、积分变化及告警等记录，恢复初始状态。

## 七、常见问题

| 遇到的情况 | 如何处理 |
|---|---|
| 订单列表为空 | 确认当前企业，并切换“我的预约／全部企业案例”和状态筛选；首次使用需先提交预约或运行案例。 |
| 只能查看，无法操作订单 | 先切换到订单所属企业；应急响应需切换到供给企业。 |
| 库容只分到一部分 | 查看分配说明；可以确认已获配部分，或调整日期另行申请。符合条件时可申请应急协作。 |
| 无法入库或配车 | 先确认预约，再登记入库；只有入库后的订单才能申请出库配车。 |
| 没有合适车辆 | 检查温区、重量、体积和时限；减少单次运量，或先完成占用车辆的运输。 |
| 扫码后查不到订单 | 二维码内容必须是完整订单号，且该订单存在于当前设备的数据中。也可手动输入查询。 |
| 朋友看不到我创建的订单 | 当前数据各自保存在设备上。转发分享的是小程序入口，不会同步你的订单或企业身份。 |
| 看不到新版界面、封面或标题 | 退出后重新打开小程序；如仍是旧版，请向组织者确认新版是否已正式发布。 |

清除小程序缓存或更换设备可能使原模拟记录无法继续使用；需要保留展示结果时，请提前截图。
