# 独立复现与发布说明

本仓库为已完结比赛项目的脱敏源码。仓库版本不代表微信正式版的发布状态，原项目账号、审核材料和后台记录不公开。

## 本地体验

1. 按 README 执行 npm run setup:wechat，创建本机工程配置。
2. 使用自己的小程序 AppID，在微信开发者工具导入工程根目录。
3. 保持 miniprogramRoot 为 miniprogram/，默认使用 local 模式。
4. 编译后体验预约、分配、入库、运输和积分流程，所有业务数据均为模拟。

真实 AppID 只写入已忽略的 project.config.json；本机开发者工具配置、密钥、预览码和截图不提交到公开仓库。

## 发布自己的版本

由自己的账号管理员根据微信公众平台当前要求核对主体、备案、服务类目、介绍和隐私说明，完成预览、体验、审核及发布。材料应准确描述模拟用途，不暗示园区官方运营或真实药品服务。上传代码、审核通过和正式发布是不同步骤，按实际后台结果记录。

发布前先运行 README 中的验证命令，再在微信模拟器与手机检查完整订单、窄屏布局、扫码入口及转发卡片。HTML 布局预览不能代替微信真机验证。

## 可选远程演示

默认本地模式无需业务服务器。需要远程演示时，使用独立的 HTTPS 接口、受支持的 Node.js 运行时、访问码与数据目录，参照 .env.example 配置进程环境变量，并在自己的小程序后台配置合法域名。

访问码通过连接弹窗输入；AppSecret、服务器凭据与实际访问码不得写入小程序包、公开配置或提交记录。当前 JSON 工作区存储适用于单进程模拟演示，不代表真实企业认证或生产业务系统。
