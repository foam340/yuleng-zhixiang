# ❄️ 渝冷智享

**让冷库与运力共享更高效。**

面向《重庆国际生物城生物药集群池化共享智慧冷链平台设计》的原生微信小程序，演示园区企业如何共享冷库与车辆，以及资源紧张时的分配、应急协作、履约和收益结算。

🎓 比赛项目 · ✅ 已完结，保留成果与复现代码 · 📱 原生微信小程序 · 📄 MIT License

> 本项目用于教学与比赛模拟。企业、资质、资源、订单、费用、温度和运输信息均为模拟数据，不提供真实药品交易、仓储、运输或医疗服务。

## 🌱 项目背景

企业各自配置冷链资源，容易出现淡季闲置、旺季短缺和重复投入。渝冷智享围绕共享联盟的运行规则，将分散的库容与运力组织为可查询、可分配、可计费的资源池。

企业保留资产所有权，按时段投放资源；需求方按需预约，供给方获得积分与模拟收入。小程序用完整的订单流程呈现这些机制：

- **贡献积分**：量化冷库投放、车辆运输和应急协作的贡献。
- **保底承诺**：先预留企业核定额度，再分配共享余量。
- **加权分配**：综合贡献、紧急程度、风险和等待时长计算优先级。
- **应急协作**：供给企业确认后锁定应急资源，履约完成后结算奖励。
- **透明结算**：展示评分、分配依据、账单、收益和申诉记录。

## 🎬 演示流程

### 完成一笔订单

1. 在工作台切换模拟企业，进入资源池查看温区与可用时段。
2. 新建一笔预约，例如冷藏 **10m³、3天、普通备货**。
3. 查看获配库容、评分明细和费用，确认预约。
4. 点击“使用模拟入库码”，完成入库登记。
5. 申请出库配车，例如本批 **10m³、1吨、120分钟内到达**。
6. 完成本批模拟运输，查看资源释放、贡献积分与账单。

积分、保底和账单入口：**我的 → 常用服务 → 积分与共享服务**。订单详情可直接进入模拟溯源档案与告警。

### 六企业旺季案例

在工作台点击“运行六企业案例”，观察冷藏需求 **750m³** 与共享冷藏库容 **500m³** 之间的竞争。

| 企业 | 需求 | 初次分配结果 |
| --- | --- | --- |
| B03 · 疫苗企业 | 冷藏200m³ | 获配200m³ |
| B05 · 临床急需企业 | 冷藏150m³ | 获配150m³ |
| B06 · 常规备货企业 | 冷藏180m³ | 保底获配150m³，剩余30m³未满足 |
| B08 · 诊断试剂企业 | 冷藏100m³ | 等待资源 |
| B12 · 新接入企业 | 冷藏120m³ | 应急待响应，供给方接受后另获应急库120m³ |
| B07 · 蛋白原液企业 | 冷冻100m³ | 从独立冷冻池150m³中获配100m³ |

应急库独立于500m³共享冷藏池。初次分配不会提前占用应急库，也不会自动保障未满足部分。

> 重新演示案例或恢复演示数据会清空当前工作区的模拟记录，操作前页面会请求确认。

## ⚙️ 规则说明

综合评分采用以下权重：

```text
综合得分 = 贡献度 × 40% + 紧急度 × 30% + 风险度 × 20% + 等待时长 × 10%
```

贡献分按同批次、同温区且时段重叠的竞争组最高积分归一化；等待越久得分越高。保底预留独立于评分，已锁定的订单不会因后续申请被强行重排。

冷库按自然日的半开区间计算占用：例如11月2日起存储3天，占用2、3、4日，5日不占用。车辆每批同时校验体积与重量，运输期间不能重复指派。

普通预约提交后即时处理，六企业案例按一批需求共同计算。当前采用规则型调度，未接入遗传算法或多车多站点路径优化求解器。

## 🚀 本地运行

### 微信小程序

1. 安装 Node.js 22及以上，在工程目录执行 `npm run setup:wechat`，从示例创建本机 `project.config.json`；已有配置会保留。
2. 安装微信开发者工具，导入本 README 所在的工程目录，使用自己的小程序 AppID。示例的游客配置用于初步查看，预览和上传需有权限的 AppID。
3. 小程序源目录为 `miniprogram/`，默认 `local` 模式。
4. 编译后进入工作台，提交预约或运行六企业案例。

默认模式无需业务服务器、AppSecret 或第三方 npm 依赖。模拟记录保存在当前设备，不同设备之间不共享订单；转发卡片只分享入口。

### 可选演示 API

后端与测试要求 **Node.js 22及以上**，使用 Node.js 内置模块。

```sh
npm start
```

默认监听本机 `127.0.0.1:5600`，健康检查路径为 `/health`。配置项见 `.env.example`；程序直接读取进程环境变量，不会自动加载 `.env`。

后端提供访问码、独立会话工作区、JSON原子持久化、同工作区请求串行处理及请求限流。文件存储适用于单进程演示。

使用远程模式时，需自行配置HTTPS服务、小程序合法域名与独立访问码，并设置 `miniprogram/config.js` 中的 `mode` 和 `apiBase`。访问码在连接弹窗输入，不写入小程序包。每个新会话创建独立工作区；该会话不代表真实企业身份认证。
